# Abhinav Mishra Portfolio

Static multi-page portfolio website for GitHub Pages.

## Pages

- `index.html`
- `about.html`
- `experience.html`
- `projects.html`
- `contact.html`

## GitHub Pages Hosting

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and `/root` folder.
6. Save. GitHub will publish the site after the Pages workflow finishes.

The site has no build step. Keep `index.html`, `style.css`, `script.js`, `photo.jpeg`, and `Abhinav_Mishra_ATS_Resume done.pdf` in the repository root.
